# Product Detail Section - Overview

## Section Purpose

Full-featured product detail page with split-screen layout (desktop/tablet) and vertical stack (mobile). Includes image gallery with zoom, size selection, quantity controls, and product information tabs.

## Component Type

Split-screen product detail with responsive image gallery and interactive product controls.

## File Structure

```
sections/product-detail.liquid
assets/section-product-detail.css
assets/section-product-detail.js
snippets/size-dropdown.liquid
```

## Requirements Checklist

- [ ] Split-screen layout (desktop/tablet)
- [ ] Vertical stack layout (mobile)
- [ ] Image gallery with 4 images
- [ ] Carousel dots (vertical on desktop/tablet, horizontal on mobile)
- [ ] Zoom button functionality
- [ ] Size selector (buttons on desktop/tablet, dropdown on mobile)
- [ ] Quantity selector with +/- controls
- [ ] Save/wishlist button
- [ ] Add to cart button with price display
- [ ] Product tabs (Description, Shipping & Returns)
- [ ] Size guide link
- [ ] Responsive breakpoints: 1440px, 1024px, 700px, 412px
